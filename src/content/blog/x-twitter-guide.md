> **先说结论**：X（原 Twitter 推特）官方网址是 `https://x.com/`。国内网络无法直接访问 X，需要通过梯子。挂了梯子还是一直加载、注册卡在验证、新号很快被锁，通常是**图片/验证域名没走代理**或**节点 IP 被大量共用**，下文逐项讲清楚。

## 一、X 官网入口是哪个？

- 官方网址：`https://x.com/`（旧地址 twitter.com 会自动跳转）
- 帮助中心：`https://help.x.com/`

X 是马斯克收购 Twitter 后改的名字，"推特""小蓝鸟""X"指的都是同一个平台。

## 二、X 怎么下载和注册？

### iPhone / iPad

国区 App Store 搜不到，需要切换到**非中国大陆地区的 Apple ID**，搜索"X"，认准开发者为 **X Corp.**。

### 安卓手机

在 **Google Play** 搜索"X"。没有 Google Play 的手机可以先看：[Google Play 安装前须知](/blog/google-play-android-guide/)。

### 电脑

直接用浏览器打开 `x.com` 即可，不需要客户端。

### 注册需要准备什么？

- 一个常用邮箱，推荐 Gmail（见 [Gmail 注册指南](/blog/gmail-register-guide/)）；
- 能稳定访问 X 的网络；
- 部分情况下会要求手机号验证，尤其是新账号触发风控时。

注册过程卡住的详细排查，见：[X 注册一直加载或卡在验证怎么办](/blog/x-twitter-loading-troubleshooting/)。

## 三、为什么 X 在国内打不开？

| 你看到的现象 | 原因 |
| --- | --- |
| 网页打不开 / App 无法连接 | 国内网络无法直连 X |
| 能打开，但图片、视频一直灰块 | 图片和视频域名没走代理，或节点带宽不足 |
| 注册时人机验证不显示、一直转圈 | 验证服务的域名没走代理，或 IP 被标记 |
| `Something went wrong. Try reloading.` | 节点不稳定、IP 被限流，或缓存问题 |
| 新注册的账号很快被锁定 | 注册环境被判定异常，常见于共用 IP 和频繁换节点 |

## 四、挂了梯子/机场，X 还是用不了？逐项排查

### 1. 图片和视频域名有没有走代理？

X 的页面、图片、视频、短链接分别用不同的域名。确认以下域名都走代理：`x.com`、`twitter.com`、`twimg.com`、`t.co`。不确定时先切**全局模式**测试。

### 2. 注册卡在人机验证

X 的人机验证由第三方服务提供，相关域名（如 `arkoselabs.com`）如果没走代理，验证框就不会显示。切全局模式试试；如果验证一直失败，换一个 IP 更干净的节点。

### 3. IP 是否被限流或标记？

频繁出现 `Something went wrong`、验证循环、新号秒锁，通常是节点 IP 被太多人共用。换同地区的其他节点，必要时换线路。

### 4. 浏览器缓存

用无痕窗口打开 `x.com`，或清除 x.com 和 twitter.com 的 Cookie 后重新登录。

### 5. 账号被锁定怎么办？

按页面提示完成验证（通常是手机号或邮箱验证）。为了降低被锁的概率：
- 注册和使用时尽量**固定同一地区、同一节点**；
- 新号不要短时间内大量关注、点赞、私信；
- 完善头像和资料，先正常浏览几天。

### 6. 手机 App 不走代理

确认代理客户端开启了 VPN / TUN 模式，X App 没有被排除在代理之外。

## 五、用 X，梯子要怎么选？

1. **IP 质量**：X 对共用 IP 的限流和风控比较明显，注册新号时尤其重要；
2. **能长期固定同一节点**：频繁跳地区容易让账号被要求验证或锁定；
3. **稳定性和带宽**：刷图片、视频和直播需要晚高峰也能稳定加载；
4. **先月付再长期**：先确认注册和日常使用都顺利，再考虑续费。

## 六、常见问题

### X 和 Twitter 是什么关系？

同一个平台。2023 年 Twitter 更名为 X，域名也从 twitter.com 换成了 x.com，但很多人仍然习惯叫它推特。

### 用国内手机号能注册 X 吗？

可以尝试，但能否收到验证码与当时的风控和运营商有关。用邮箱注册是更常见的做法，后续需要时再绑定手机号。

### 注册后关注哪些账号比较好？

按兴趣搜索即可，比如 AI 领域可以关注 OpenAI、Anthropic、Google DeepMind 等官方账号。新号先正常浏览、少量关注，比一次性大量关注更安全。
