> **先说结论**：「魔法上网」「科学上网」「翻墙」说的是同一件事：通过代理工具访问海外网站。「梯子」是工具的统称，「机场」是提供多个节点、按套餐收费的代理服务，「节点」是你实际连接的那台服务器。看懂这几个词，教程和机场介绍就不难懂了。

## 一、基础术语

| 术语 | 意思 |
| --- | --- |
| 魔法上网 / 科学上网 / 翻墙 | 通过代理工具访问 Google、YouTube、GitHub 等海外网站 |
| 梯子 | 所有翻墙工具的统称，比喻「翻过墙的梯子」 |
| 机场 | 提供多个节点、按流量或时长收费的代理服务。名称来自 Shadowsocks 的纸飞机图标，飞机停的地方就是「机场」 |
| VPN | 一种通用的加密网络技术，常被用来泛指翻墙工具 |
| 节点 | 分布在各地的服务器，如香港节点、日本节点，你的流量从这里出去访问网站 |
| 订阅链接 | 机场提供的一个网址，导入客户端后自动获取全部节点，用法见 [订阅链接怎么用](/blog/subscription-link-guide/) |
| 客户端 | 连接节点用的软件，如 Clash、Shadowrocket（小火箭）、sing-box，用法见 [Clash 教程](/blog/clash-verge-guide/)、[小火箭教程](/blog/shadowrocket-guide/) |

## 二、线路相关术语

### 直连、中转与专线

- **直连**：你的设备直接连到海外节点，经过公网国际出口，晚上用网高峰时容易变慢；
- **中转**：先连到国内的中转服务器，再转发到海外节点，线路更稳定；
- **专线（IPLC / IEPL）**：中转之后，跨境这一段走运营商出租的专用线路，**不经过公网国际出口**，所以晚高峰受拥堵影响较小。

### IPLC 和 IEPL 有什么不同？

- **IPLC**（国际私有租用线路）：传统的点对点跨境专线；
- **IEPL**（国际以太网专线）：基于以太网的跨境专线。

对普通用户来说，两者都算「专线」，体验差别不大，详细对比见 [IPLC 和 IEPL 有什么区别](/blog/iplc-vs-iepl/)。需要注意的是，专线主要改善的是**稳定性和晚高峰速度**，并不代表「永远不会断」，线路维护或故障时同样会受影响。

### BGP

指入口服务器接入了多家运营商的线路，电信、联通、移动用户会自动走较优的路线，常见写法如「BGP 中转」「BGP-IEPL」。

## 三、协议相关术语

| 协议 | 简介 |
| --- | --- |
| Shadowsocks（SS） | 老牌轻量协议，很多机场仍在使用 |
| VMess / VLESS | V2Ray / Xray 项目的协议，VLESS 更轻量 |
| Trojan | 伪装成普通 HTTPS 流量的协议 |
| Hysteria2、TUIC | 基于 UDP 的协议，弱网环境下表现较好 |

一般用户不需要自己选协议，按机场推荐的客户端导入订阅即可。

## 四、网站为什么打不开？

常见的拦截方式有三种：

- **DNS 污染**：查询网址时返回错误的地址，导致连不上；
- **SNI 阻断**：在建立 HTTPS 连接时识别出目标网站并中断连接；
- **IP 封锁**：直接屏蔽目标服务器的 IP。

代理工具的作用，就是把你的请求加密后送到海外节点，再由节点去访问目标网站。

## 五、常见的「黑话」

- **倍率**：节点用 1GB 扣多少流量，标「2x」表示用 1GB 扣 2GB；
- **跑路**：机场突然停止服务、联系不上；
- **晚高峰**：一般指晚上 20:00–23:00，用网人数最多的时段；
- **解锁**：能正常使用 Netflix、ChatGPT 等有地区限制的服务；
- **全局 / 规则模式**：全局是所有流量都走代理，规则是只有海外网站走代理。

## 六、新手选梯子的三个原则

1. **不碰来源不明的免费节点**：稳定性差，也可能有隐私风险，详见 [免费梯子靠谱吗](/blog/free-vpn-risk/)；
2. **先买月付**：每个人所在地区和宽带不同，先用一个月确认好用再续费；
3. **看清线路类型和倍率**：分清「专线」和「直连」，留意节点名称上的倍率标记。
