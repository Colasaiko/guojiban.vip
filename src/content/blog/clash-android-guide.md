> **先说结论**：安卓手机用 Clash，推荐 **Clash Meta for Android** 或 **FlClash**，两者都在 GitHub 开源发布、免费使用。操作和电脑版一样：**安装 → 导入订阅链接 → 选节点 → 启动**。国产手机还要额外设置后台保活，否则锁屏后容易断线。

## 一、选哪个客户端？

| 客户端 | 特点 | 适合 |
| --- | --- | --- |
| **Clash Meta for Android** | 基于 mihomo（Clash Meta）内核，功能完整、更新稳定 | 大多数用户 |
| **FlClash** | 界面简洁现代，支持安卓、Windows、macOS 多平台 | 想要电脑和手机界面一致的用户 |
| 原版 Clash for Android | 已停止更新 | 不建议使用 |

> 如果你用的是主推品牌的**专属客户端**（登录账号即用），就不需要 Clash；本教程适合手上有订阅链接的用户。

## 二、下载与安装

**只从官方 GitHub 下载**：

- Clash Meta for Android：在 GitHub 搜索「ClashMetaForAndroid」（MetaCubeX 发布），进入 Releases；
- FlClash：在 GitHub 搜索「FlClash」，进入 Releases。

### 下载哪个安装包？

安装包通常按处理器架构区分：

- **arm64-v8a**：近几年的绝大多数安卓手机选这个；
- **armeabi-v7a**：很老的 32 位手机；
- **universal**：通用版，体积较大，不确定时可以选它。

下载后点击安装，如果提示「禁止安装未知来源应用」，按提示允许浏览器或文件管理器安装即可。来路不明的「Clash 中文版」「破解版」不要安装。

## 三、Clash Meta for Android 使用步骤

1. 打开 App，点击「**配置**」；
2. 点击右上角「**+**」→ 选择「**URL**」；
3. 「名称」随意填写，「URL」粘贴机场的订阅链接（选 Clash 格式，见 [订阅链接怎么用](/blog/subscription-link-guide/)），点击右上角保存；
4. 回到配置列表，**点选**刚才添加的配置；
5. 回到首页，点击「**已停止**」启动，第一次会弹出 VPN 连接请求，点击「确定」；
6. 点击「**代理**」，选择延迟较低的节点；右上角菜单可以切换「规则 / 全局 / 直连」模式，日常用「规则」。

## 四、FlClash 使用步骤

1. 打开 FlClash，进入「**配置**」，点击「**+**」→「URL」；
2. 粘贴订阅链接，确认导入并选中这个配置；
3. 回到「仪表盘」，点击启动按钮，允许 VPN 连接；
4. 在「代理」页选择节点，模式选「规则」。

## 五、国产手机一定要做：后台保活

小米、OPPO、vivo、华为、荣耀等系统会主动清理后台，Clash 被杀掉后就会断线。建议：

1. **电池优化**：设置 → 应用 → Clash → 耗电管理 / 电池，改为「**无限制**」或「允许后台运行」；
2. **自启动**：在手机管家或应用设置中，允许 Clash **自启动**；
3. **锁定后台**：打开多任务界面，下拉或长按 Clash 卡片，选择「锁定」；
4. **通知栏常驻**：不要关闭 Clash 的通知权限，常驻通知可以降低被清理的概率。

不同品牌的入口名称不同，可以在设置里搜索「电池」「自启动」「后台」。

## 六、常见问题

### 导入订阅失败？

- 检查链接是否完整、是否已过期；
- 订阅地址在国内打不开时，可以换网络或先用其他方式连上代理再更新；
- 确认是 Clash 格式的订阅。部分机场给的是 V2Ray 通用链接，这种情况可以在机场后台换成 Clash 订阅。

### 已经连上，但 App 或网页打不开？

1. 在「代理」页测速，确认节点没有超时；
2. 临时切换「全局」模式测试，能打开说明是规则问题；
3. 更新订阅，节点可能已经变更；
4. 检查套餐是否到期、流量是否用完。

### 为什么锁屏一段时间后就断线？

基本都是被系统清理了后台，按第五节设置保活。

### 和 v2rayNG 有什么区别？

v2rayNG 也是常见的安卓客户端，适合导入 VMess、VLESS 等单个节点链接；Clash 系客户端更擅长订阅管理和规则分流。用哪个取决于机场提供的订阅格式。

## 七、总结

安卓用 Clash 不难，关键是**从 GitHub 下载正版**、导入正确格式的订阅，以及**设置好后台保活**。
