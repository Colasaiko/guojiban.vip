> **先说结论**：Midjourney 官方网址是 `https://www.midjourney.com/`，现在可以**直接在网页版生成图片**，不一定要用 Discord。国内网络无法直接访问，需要通过梯子。挂了梯子还是图片出不来、页面一直验证，通常是**图片域名没走代理**或**节点 IP 被标记**，下文逐项讲清楚。

## 一、Midjourney 官网入口是哪个？

- 官方网址：`https://www.midjourney.com/`
- 官方 Discord 服务器：从官网页面进入，不要通过来源不明的邀请链接加入

Midjourney 是付费工具，需要订阅后才能生成图片，具体套餐和价格以官网为准。网上的"免费 MJ""MJ 中文版"多为第三方转接站，**不要在这些网站输入账号或付款信息。**

## 二、网页版和 Discord，用哪个？

| 对比 | 网页版 | Discord |
| --- | --- | --- |
| 入口 | 浏览器打开 midjourney.com | 在 Discord 里和 Midjourney 机器人交互 |
| 操作 | 输入框 + 可视化参数调节，更直观 | 输入 `/imagine` 加提示词 |
| 图片管理 | 自带作品库，方便整理和搜索 | 图片混在聊天记录里 |
| 适合 | 新手、日常创作 | 已习惯 Discord、喜欢在社区里看别人作品 |

**新手建议直接用网页版**。两种方式用的是同一个账号和同一份订阅额度。

用 Discord 方式的话，Discord 本身的下载和网络问题见：[Discord 下载注册与 RTC 连接排查](/blog/discord-download-register/)。

### 手机上能用吗？

Midjourney 没有官方手机 App，手机上用浏览器打开网页版即可。应用商店里叫"Midjourney"的 App 基本都是第三方的，注意辨别。

## 三、为什么 Midjourney 在国内打不开？

| 你看到的现象 | 原因 |
| --- | --- |
| 网页打不开 | 国内网络无法直连 Midjourney |
| 页面一直出现人机验证 | 节点 IP 被大量共用或被标记 |
| 能打开，但生成的图片一直加载不出来 | 图片域名没走代理，或节点带宽不足 |
| Discord 里机器人不回复 | Discord 连接不稳定，或订阅未生效 |

## 四、挂了梯子/机场，Midjourney 还是用不了？逐项排查

### 1. 图片域名有没有走代理？

Midjourney 的页面和图片来自不同域名，图片走的是 `cdn.midjourney.com`。确认 `midjourney.com` 和 `cdn.midjourney.com` 都走代理；用 Discord 方式时，Discord 相关域名也要走代理。不确定时先切**全局模式**测试。

### 2. 一直人机验证

说明节点 IP 被标记了。换同地区的其他节点；如果整家服务的节点都这样，说明 IP 质量不适合。

### 3. 浏览器缓存

用无痕窗口打开，或清除 midjourney.com 的 Cookie 后重新登录。

### 4. Discord 机器人不响应

- 先确认网页版能正常生成，排除订阅问题；
- 再按 [Discord 排查文章](/blog/discord-download-register/) 检查 Discord 连接。

### 5. 生成速度慢

生成速度主要取决于你的订阅套餐和服务器负载，和梯子关系不大；但**图片加载慢**是网络问题，换带宽更好的节点即可改善。

## 五、用 Midjourney，梯子要怎么选？

1. **IP 质量**：频繁人机验证会严重影响使用体验；
2. **带宽**：高清大图和批量浏览作品库对带宽有一定要求；
3. **稳定性**：生成过程中断线可能需要重新提交；
4. **先月付再长期**：先确认能稳定打开和出图，再考虑续费。
