> **先说结论**：现在电脑上用 Clash，推荐 **Clash Verge Rev**（基于 mihomo / Clash Meta 内核，支持 Windows、macOS、Linux）。流程只有四步：**下载安装 → 导入订阅链接 → 选择节点 → 打开系统代理**。原来的 Clash for Windows、ClashX 已经停止更新，不建议再用。

## 一、Clash 是什么？为什么推荐 Clash Verge Rev？

Clash 是一类代理客户端，本身不提供节点。你需要先有机场或梯子服务的**订阅链接**，再把它导入 Clash 使用。

| 客户端 | 状态 | 说明 |
| --- | --- | --- |
| Clash for Windows | 已停止更新 | 2023 年作者停更，存在安全隐患，不建议继续使用 |
| ClashX（Mac） | 已停止更新 | 同上 |
| **Clash Verge Rev** | 持续更新 | 界面中文、支持 Windows / macOS / Linux，推荐 |
| FlClash、Clash Nyanpasu 等 | 持续更新 | 也可以使用，操作逻辑类似 |

> 如果你用的是主推品牌的**专属客户端**（登录账号即可连接），就不需要 Clash；本教程适合手上有订阅链接的用户。

## 二、下载与安装

**只从官方 GitHub 下载**：在 GitHub 搜索「clash-verge-rev」，进入项目的 Releases 页面下载最新版本。网上很多「Clash 中文版」「Clash 汉化版」下载站来路不明，可能被植入恶意程序。

### Windows

1. 下载文件名带 `x64-setup.exe` 的安装包（ARM 处理器的电脑选 `arm64`）；
2. 双击安装，按提示完成；
3. 系统需要 Windows 10 或以上。如果打开后白屏，可能缺少微软 WebView2 组件，到微软官网安装后重试。

### macOS

1. Apple 芯片（M 系列）选 `aarch64.dmg`，Intel 芯片选 `x64.dmg`；
2. 打开 dmg，把应用拖进「应用程序」；
3. 如果提示「无法打开」或「已损坏」，到 **系统设置 → 隐私与安全性**，在下方点击「仍要打开」。

## 三、导入订阅链接

1. 在机场后台复制你的**订阅链接**（一般在「一键订阅」或「复制订阅地址」里，选 Clash 格式）；
2. 打开 Clash Verge Rev，点击左侧「**订阅**」；
3. 把链接粘贴到上方输入框，点击「**导入**」；
4. 导入成功后，点击这个订阅卡片，让它变成**当前使用**的配置。

订阅链接相当于你的账号密码，**不要发给别人，也不要贴在公开的地方**。

## 四、选择节点并开启代理

1. 点击左侧「**代理**」，可以看到所有节点；
2. 点击右上角的测速图标，测试各节点延迟，选择延迟较低、没有超时的节点；
3. 上方模式选择「**规则**」（推荐）：国内网站直连、海外网站走代理；
4. 点击左侧「**设置**」，打开「**系统代理**」开关；
5. 打开浏览器访问 google.com 或 youtube.com，能正常打开就完成了。

### 三种模式怎么选？

| 模式 | 效果 | 适合情况 |
| --- | --- | --- |
| 规则 | 按规则分流，国内直连、海外走代理 | 日常使用，推荐 |
| 全局 | 所有网站都走代理 | 某个网站打不开时临时排查 |
| 直连 | 完全不走代理 | 暂时关闭代理 |

## 五、什么时候需要开 TUN 模式（虚拟网卡）？

「系统代理」只对遵守系统代理设置的软件有效，浏览器大多没问题。但有些软件不走系统代理，例如部分游戏客户端、终端命令行、某些 AI 编程工具。这时可以：

1. 在「设置」中开启 **虚拟网卡模式（TUN）**；
2. Windows 第一次开启时需要安装「服务模式」，macOS 需要输入电脑密码授权；
3. 开启 TUN 后，可以关闭系统代理，避免重复。

例如 Cursor 等编程工具连不上 AI 时，就常常需要 TUN 模式，详见 [Cursor 国内使用指南](/blog/cursor-ai-guide/)。

## 六、日常使用技巧

- **自动更新订阅**：在订阅卡片的编辑选项里设置更新间隔，节点变动时会自动同步；
- **开机自启**：在设置里打开「开机自启」和「静默启动」，开机后自动在后台运行；
- **固定节点**：注册账号、登录 AI 工具时尽量固定同一地区的节点，频繁切换容易触发风控；
- **端口**：其他软件需要手动填写代理时，在设置里查看「端口设置」（Clash Verge Rev 默认混合端口一般是 7897，以设置页显示为准）。

## 七、常见问题

### 导入订阅时提示失败？

- 检查链接是否复制完整，是否已过期（机场后台重置过订阅会失效）；
- 部分机场的订阅地址在国内无法直接访问，可以在订阅设置中开启「使用 Clash 代理更新」，或换网络再试；
- 确认复制的是 Clash 格式的订阅。

### 已经连上，但网页还是打不开？

1. 确认「系统代理」开关已经打开；
2. 浏览器装了 SwitchyOmega 等代理插件的，先停用插件；
3. 切到「全局」模式测试，能打开说明是规则问题，否则换节点；
4. 测速全部超时，可能是订阅过期、流量用完或服务端故障。

### 关掉 Clash 后上不了网？

一般是 Clash 异常退出时没有还原系统代理。重新打开 Clash 再正常退出，或到系统的代理设置中手动关闭代理。

### 手机能用 Clash 吗？

可以。安卓用 Clash Meta 或 FlClash，见 [安卓手机怎么用 Clash](/blog/clash-android-guide/)；iPhone 推荐用 Shadowrocket，见 [Shadowrocket（小火箭）怎么用](/blog/shadowrocket-guide/)。

## 八、总结

Clash Verge Rev 的核心就是「导入订阅 → 选节点 → 开系统代理」。日常用规则模式，遇到不走代理的软件再开 TUN。
