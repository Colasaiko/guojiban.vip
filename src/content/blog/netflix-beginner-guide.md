> **先说结论**：Netflix（俗称“奈飞”“网飞”）官方网址是 `https://www.netflix.com/`。Netflix 没有在中国大陆提供服务，国内网络也无法直接访问，需要一条**能解锁 Netflix 的稳定线路**才能观看。挂了梯子能打开、却只能看自制剧或提示代理错误，问题几乎都出在**节点 IP 是否被 Netflix 认可**，下文逐项讲清楚。

## 一、Netflix 官网入口是哪个？

- 官方网址：`https://www.netflix.com/`
- 帮助中心：`https://help.netflix.com/`

网上的"奈飞免费看""Netflix 共享账号"等站点和链接，大多是盗版或钓鱼页面，**不要在来源不明的网站输入 Netflix 账号密码或银行卡信息。**

## 二、Netflix 怎么下载？

### iPhone / iPad

国区 App Store 搜不到 Netflix，需要切换到**非中国大陆地区的 Apple ID**，搜索"Netflix"，认准开发者为 **Netflix, Inc.**。

### 安卓手机

在 **Google Play** 搜索"Netflix"。部分国产手机没有通过 Google 认证，商店里可能搜不到或无法安装，可以先看：[Google Play 安装前须知](/blog/google-play-android-guide/)。

### 电脑

直接用浏览器打开 `netflix.com` 即可观看。不同浏览器和系统支持的最高画质不同，想看高清或 4K，Windows 上可以用 Edge 或 Microsoft Store 里的 Netflix 应用，Mac 上推荐 Safari。

### 电视 / 电视盒子

电视看 Netflix 需要设备本身支持 Netflix 应用，并且网络能解锁。具体方法见：[电视怎么看 Netflix](/blog/netflix-tv-setup/)。

## 三、为什么 Netflix 在国内打不开？

| 你看到的现象 | 原因 |
| --- | --- |
| 网页打不开 / App 一直加载 | 国内网络无法直连 Netflix |
| 能打开，但只能看到带 N 标的自制剧 | 节点 IP 没有被 Netflix 认可为当地用户，只开放全球版权的自制内容 |
| `M7111-5059` / 提示你似乎在使用代理或解锁工具 | 节点 IP 被 Netflix 识别为代理，拒绝播放 |
| 能播放但一直缓冲、画质很糊 | 线路带宽不足或晚高峰拥堵 |

## 四、挂了梯子/机场，Netflix 还是看不了？逐项排查

### 1. 节点支不支持 Netflix 解锁？

这是最关键的一点。能"翻出去"不等于能看 Netflix。Netflix 会识别机房 IP 和代理 IP，**只有商家专门做了流媒体解锁的节点才能正常看全部片库**。很多服务会在节点名里标注"Netflix""流媒体""解锁"，优先选这类节点。

### 2. 只能看自制剧怎么办？

说明当前节点是"半解锁"。换同一服务里标注流媒体解锁的其他节点；如果全部节点都只能看自制剧，说明这家服务不支持完整解锁 Netflix。

### 3. 分流规则有没有让 Netflix 走代理？

规则模式下，Netflix 的视频流使用多个域名，漏掉其中一个就可能出现"页面能开、视频播不了"。确认以下域名都走代理：`netflix.com`、`nflxvideo.net`、`nflximg.net`、`nflxext.com`、`nflxso.net`。不确定时先切**全局模式**测试。

### 4. 片库和预期不一样

Netflix 每个国家/地区的片库不同，你看到的内容取决于节点所在地区。想看某部剧搜不到，可以换到其他地区的解锁节点试试，比如美国、日本、新加坡、台湾。

### 5. 一直缓冲、画质低

- 晚高峰尽量选择专线类、负载较低的节点；
- 确认会员套餐本身支持高清或 4K（基础套餐画质有上限）；
- 电视和电视盒子尽量用有线网络，Wi-Fi 信号弱也会导致卡顿。

### 6. 手机 App 不走代理

浏览器能看、App 不行，确认代理客户端开启了 VPN / TUN 模式，并且 Netflix App 没有被排除在代理之外。

## 五、看 Netflix，梯子要怎么选？

1. **明确支持 Netflix 解锁**：这是硬条件，购买前看商家是否标明支持 Netflix，以及支持哪些地区；
2. **带宽和晚高峰稳定性**：高清和 4K 对持续带宽要求高，晚高峰降速会直接表现为缓冲和画质下降；
3. **有多个地区的解锁节点**：方便切换不同地区片库；
4. **先月付再长期**：解锁情况会随 Netflix 的检测策略变化，先买一个月实际测试，确认能稳定观看再续费。

## 六、常见问题

### Netflix 会员怎么开通？

在 `netflix.com` 注册后选择套餐并付款。付款通常需要支持地区的银行卡，或使用 Netflix 礼品卡。不同地区的套餐价格不同，以官网显示为准。

### 合租 Netflix 账号会被封吗？

Netflix 已经限制同一账号在不同"家庭"之间共享，异地合租可能被要求验证或加购"额外成员"。合租前要了解这个风险，避免付了钱却用不了。

### 为什么昨天能看，今天提示代理错误？

Netflix 会持续更新代理 IP 检测，节点今天能用、明天被识别是常见情况。先换同服务的其他解锁节点；如果频繁出现，说明这家服务的解锁维护跟不上。

### 电视怎么看 Netflix？

需要电视或盒子支持 Netflix 应用，并让电视的网络走代理，常见做法是路由器或旁路由。详见：[电视怎么看 Netflix](/blog/netflix-tv-setup/)。
