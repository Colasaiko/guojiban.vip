> **先说结论**：订阅链接是机场给你的一个网址，客户端定期访问它，就能自动获取并更新全部节点。用法很简单：**在机场后台复制对应格式的订阅 → 粘贴到客户端 → 开启自动更新**。格式不对时可以做「订阅转换」，但**尽量不要用来路不明的在线转换网站**，订阅链接一旦泄露，别人就能用你的套餐。

## 一、订阅链接是什么？

购买机场服务后，后台会给你一个类似 `https://xxx.com/api/v1/client/subscribe?token=...` 的网址，这就是订阅链接：

- 里面包含**全部节点**的信息，不用一个个手动添加；
- 机场增减节点、更换 IP 时，客户端更新订阅就能同步；
- 很多客户端还能显示**剩余流量和到期时间**。

> 主推品牌大多提供**专属客户端**，登录账号即可连接，不需要自己处理订阅链接。本文适合使用 Clash、小火箭、v2rayN 等通用客户端的用户。

## 二、常见的订阅格式

| 格式 | 内容形式 | 适用客户端 |
| --- | --- | --- |
| **Clash / mihomo** | YAML 配置文件，含节点和分流规则 | Clash Verge Rev、Clash Meta for Android、FlClash、Stash |
| **V2Ray 通用** | Base64 编码的节点链接列表（vmess://、vless://、trojan:// 等） | v2rayN、v2rayNG、Shadowrocket |
| **Shadowrocket** | 机场专门为小火箭生成的格式 | Shadowrocket |
| **sing-box** | JSON 配置文件 | sing-box、部分新客户端 |
| **Surge / Quantumult X** | 各自的配置格式 | 对应客户端 |

**最省事的做法**：在机场后台的「一键订阅」或「复制订阅」菜单里，直接选你所用客户端对应的格式。

## 四、记得开启自动更新

订阅导入后，节点不会自己变化，需要定期更新：

- **Clash Verge Rev**：在订阅卡片的编辑选项中设置更新间隔（例如 12 或 24 小时）；
- **Shadowrocket**：设置 → 订阅 → 打开「打开时更新」；
- **v2rayN**：订阅分组设置中可以设置自动更新间隔；
- **安卓 Clash**：配置的编辑页面中设置自动更新。

节点突然全部超时，第一步就是**手动更新一次订阅**，很多时候只是机场换了 IP。

## 五、订阅转换是什么？要不要用？

订阅转换就是把一种格式转成另一种，例如把 V2Ray 通用订阅转成 Clash 格式，或者给配置加上自定义分流规则。

### 三种转换方式

| 方式 | 说明 | 风险 |
| --- | --- | --- |
| **机场后台自带的多种格式** | 直接复制对应格式的订阅 | 最低，**优先使用** |
| **客户端自带的转换** | 部分客户端能直接识别多种格式 | 低 |
| **第三方在线转换网站** | 把订阅链接粘贴到网站，生成新的链接 | **高**，网站运营者能看到你的订阅链接 |

### 为什么要小心在线转换网站？

使用在线转换时，你的订阅链接会发送到对方的服务器。对方如果记录下来，就能用你的套餐、消耗你的流量，甚至把节点公开分享出去。另外：

- 部分机场**明确禁止使用第三方订阅转换**，发现后可能封禁订阅；
- 也有机场已经关闭订阅转换的支持，转换后的订阅无法更新；
- 有技术能力的用户可以自己部署开源的转换工具（例如 subconverter），只在自己的服务器上处理。

**结论**：先看机场后台有没有你要的格式，没有的话问客服，最后才考虑转换。

## 六、订阅链接的安全

- **不要发给别人，也不要贴在群里或截图公开**：链接里的 token 就相当于账号密码；
- **怀疑泄露就立刻重置**：在机场后台点击「重置订阅」，旧链接会失效，然后在自己的客户端重新导入；
- **流量异常消耗时**：先检查是否有设备在后台下载，再考虑订阅是否泄露。

## 七、常见问题

### 导入后节点数量是 0？

- 订阅格式和客户端不匹配，换成对应格式；
- 套餐已到期或流量用完，后台显示的节点会被清空；
- 订阅地址在当前网络下打不开，换网络或先连上其他可用代理再更新。

### 更新订阅提示失败或超时？

- 链接是否完整、是否已经重置过；
- 部分机场的订阅地址在国内打不开，可以选择「通过代理更新」；
- 有些机场限制订阅更新的频率或来源，请按官方说明操作。

### 一个订阅可以在几台设备上用？

取决于机场的规定。有些不限设备数，有些限制同时在线数量，请看套餐说明。

### 订阅链接和节点链接有什么区别？

节点链接（vless://、vmess:// 等）只包含一个节点；订阅链接包含全部节点，并且可以自动更新。
