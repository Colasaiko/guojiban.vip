> **先说结论**：v2rayN 是 Windows 上最常用的免费代理客户端之一（新版也支持 macOS、Linux），内置 Xray、sing-box 等内核，支持 VMess、VLESS、Trojan、Shadowsocks、Hysteria2 等协议。使用流程是：**下载解压 → 添加订阅 → 更新订阅 → 选节点 → 开系统代理**。

## 一、v2rayN 和 Clash 有什么区别？

| 对比项 | v2rayN | Clash Verge Rev |
| --- | --- | --- |
| 适合的订阅 | V2Ray 通用订阅（节点链接列表） | Clash 格式订阅（YAML 配置） |
| 分流方式 | 内置路由规则（如「绕过大陆」） | 由订阅配置里的规则决定 |
| 上手难度 | 中等，界面选项较多 | 较简单 |
| 平台 | Windows 为主，新版支持 macOS / Linux | Windows / macOS / Linux |

**怎么选**：机场给的是 Clash 订阅，就用 [Clash Verge Rev](/blog/clash-verge-guide/)；给的是 V2Ray 通用订阅或单个 vless:// 链接，就用 v2rayN。很多机场两种都提供。

> 如果你用的是主推品牌的**专属客户端**（登录账号即用），就不需要 v2rayN；本教程适合手上有订阅链接的用户。

## 二、下载与安装

1. 在 GitHub 搜索「v2rayN」（作者 2dust），进入 Releases 页面；
2. Windows 用户下载文件名带 **windows-64** 的压缩包，优先选择带 **With-Core**（内置内核）的版本；
3. 解压到一个固定的文件夹（例如 `D:\v2rayN`），不要放在桌面或临时文件夹；
4. 双击 `v2rayN.exe` 运行，程序会出现在右下角任务栏。

**运行环境**：新版 v2rayN 基于 .NET 运行。打开时如果提示缺少 .NET 运行环境，按提示到微软官网安装「.NET 桌面运行时」，或下载 Releases 中自带运行环境的版本。

**安全提醒**：只从官方 GitHub 下载。网上的「v2rayN 中文版」「绿色版」来路不明，可能被植入恶意程序。

## 三、添加订阅

1. 在机场后台复制订阅链接（选 V2Ray / 通用格式，格式区别见 [订阅链接怎么用](/blog/subscription-link-guide/)）；
2. 打开 v2rayN，点击菜单「**订阅分组**」→「**订阅分组设置**」；
3. 点击「**添加**」，备注填机场名称，「可选地址（url）」粘贴订阅链接，点击「确定」；
4. 回到主界面，点击「订阅分组」→「**更新全部订阅（不通过代理）**」；
5. 节点列表出现后，说明导入成功。

只有单个节点链接（vless:// 等）时：复制链接，在主界面按 `Ctrl + V`，或从「服务器」菜单选择「从剪贴板导入」。

## 四、测速并选择节点

1. 全选节点（`Ctrl + A`），右键选择「**测试服务器真连接延迟**」；
2. 等待测速结束，选择延迟较低、没有显示超时的节点；
3. 双击节点或按回车，设为**活动服务器**（左侧会出现标记）。

## 五、开启代理与路由设置

1. 在主界面底部（或右键任务栏图标）找到「系统代理」，选择「**自动配置系统代理**」；
2. 「路由」选择「**绕过大陆（Whitelist）**」：国内网站直连、海外网站走代理，日常推荐；
3. 打开浏览器访问 google.com，能打开就完成了。

### 三种系统代理选项

| 选项 | 效果 |
| --- | --- |
| 自动配置系统代理 | 开启代理，日常使用 |
| 清除系统代理 | 关闭代理，恢复直连 |
| 不改变系统代理 | v2rayN 不修改系统设置，适合手动配置的高级用户 |

### 需要让所有软件都走代理？

部分软件（游戏、命令行、AI 编程工具）不读取系统代理，可以在设置中开启 **Tun 模式**，第一次开启需要以管理员身份运行 v2rayN。

## 六、常见问题

### 更新订阅失败？

- 确认订阅链接完整、没有过期；
- 先试「不通过代理」更新；如果订阅地址在国内打不开，再连上一个可用节点后选「通过代理更新」；
- 确认订阅格式是 V2Ray 通用格式，Clash 格式的订阅 v2rayN 可能无法识别。

### 显示已连接，但网页打不开？

1. 确认底部系统代理是「自动配置系统代理」；
2. 浏览器装了代理插件的先停用；
3. 换一个测速正常的节点；
4. 路由临时改为「全局」测试，能打开说明是路由规则问题。

### 关闭 v2rayN 后上不了网？

v2rayN 异常退出时可能没有还原系统代理。重新打开 v2rayN，选择「清除系统代理」后再退出，或在 Windows 设置 → 网络 → 代理中关闭手动代理。

### 杀毒软件报毒？

代理软件会修改系统代理设置，部分杀毒软件会误报。只要是从官方 GitHub 下载的版本，可以加入信任列表。

## 七、总结

v2rayN 适合使用 V2Ray 通用订阅的用户：**更新订阅 → 测速 → 设活动服务器 → 自动配置系统代理 → 路由选绕过大陆**，五步就能用。

电脑上也可以用 [Clash Verge Rev](/blog/clash-verge-guide/)，手机端见 [Shadowrocket（小火箭）教程](/blog/shadowrocket-guide/) 和 [安卓 Clash 教程](/blog/clash-android-guide/)。还没有订阅链接，可以参考 [2026 梯子推荐与选购指南](/tizi/)。
