> **先说结论**：电报、纸飞机、TG、Telegram 指的是同一款软件，官网是 `https://telegram.org/`。国内网络无法直接连接 Telegram，打开会一直显示"连接中 / Connecting"。挂了梯子还连不上，最常见的原因是 **Telegram 用 IP 直连，规则模式只写了域名没写 IP 段**，下文逐项讲清楚。

## 一、Telegram 是什么？官网入口是哪个？

Telegram 是一款海外即时通讯软件，因为 Logo 是纸飞机，中文圈常叫它"纸飞机""电报"或"TG"。

- 官方网址：`https://telegram.org/`
- 网页版：`https://web.telegram.org/`
- 电脑版下载：`https://desktop.telegram.org/`

和微信相比，Telegram 的特点是：
- **云端同步**：聊天记录保存在云端，换手机登录即可恢复；
- **大文件传输**：单个文件上限比大多数聊天软件高得多；
- **频道和超大群组**：很多海外资讯、工具和社区都通过频道发布；
- **秘密聊天**：只有"秘密聊天（Secret Chat）"是端到端加密的，普通聊天是云端聊天，两者不要混淆。

> **当心山寨版**：网上的"Telegram 中文版""国内特供版"大多是改包，可能窃取聊天记录或钱包信息。中文界面用官方版设置即可，见 [Telegram 怎么设置中文](/blog/telegram-chinese-setting/)。

## 二、Telegram 怎么下载和注册？

### iPhone / iPad

国区 App Store 搜不到，需要切换到**非中国大陆地区的 Apple ID**，搜索"Telegram Messenger"，认准开发者为 **Telegram FZ-LLC**。

### 安卓手机

- **Google Play** 搜索"Telegram"；
- 没有 Google Play 时，可以从官网 `telegram.org/android` 下载**官方安装包**，不要从其他网站下载。

### 电脑

从 `desktop.telegram.org` 下载 Windows / Mac / Linux 客户端，或直接用网页版。

### 注册需要什么？

Telegram 用**手机号**注册。验证码可能通过短信发送，也可能发到你已登录的其他 Telegram 设备上。国内手机号有时会遇到收不到验证码的情况，可以稍等后重新发送，或检查手机是否拦截了国际短信。

## 三、为什么 Telegram 在国内连不上？

| 你看到的现象 | 原因 |
| --- | --- |
| 一直显示"连接中 / Connecting" | 国内网络无法直连 Telegram 服务器 |
| 开了梯子仍然"连接中" | Telegram 走 IP 直连，代理规则没覆盖它的 IP 段 |
| 文字能收发，图片和文件一直转圈 | 节点带宽不足或不稳定 |
| 收不到登录验证码 | 短信通道或号码的问题，与网络无关时需要等待重试 |

## 四、挂了梯子/机场，Telegram 还是连不上？逐项排查

### 1. 规则有没有覆盖 Telegram 的 IP 段？

这是 Telegram 和其他 App 最不一样的地方。Telegram 客户端很多时候**直接用 IP 地址连接服务器**，不经过域名。如果代理规则只写了 `telegram.org`、`t.me` 这类域名，流量仍然会直连失败。

解决方法：
- 先切**全局模式**测试，能连上就说明是规则问题；
- 使用梯子服务商提供的完整规则（通常已包含 Telegram 的 IP 段）；
- 或手动在规则里加入 Telegram 官方公布的 IP 段（如 `91.108.0.0/16`、`149.154.160.0/20` 等）走代理。

### 2. 手机上是否开启了 VPN / TUN 模式？

只设置系统 HTTP 代理时，Telegram 的流量可能不经过代理。确认客户端开启的是 VPN / TUN 模式。

### 3. Telegram 内置代理设置冲突

如果你之前在 Telegram 里手动填过代理（设置 → 数据和存储 → 代理），而那个代理已经失效，会一直连接中。用梯子时，把 Telegram 内置代理**关闭**，让流量走系统 VPN。

### 4. 图片、文件一直转圈

文字能发说明已经连上了，问题在带宽：
- 换负载更低的节点；
- 晚高峰尤其明显时，说明线路高峰期不稳定。

### 5. 节点地区

Telegram 对节点地区要求不严格，香港、日本、新加坡等节点一般都可以。连不上时优先排查规则，而不是换地区。

## 五、用 Telegram，梯子要怎么选？

1. **规则完整**：服务商提供的规则要包含 Telegram 的 IP 段，否则会频繁"连接中"；
2. **长连接稳定**：Telegram 需要一直保持在线才能及时收到消息，节点频繁断开会导致消息延迟；
3. **带宽**：经常收发图片、视频、大文件的话，晚高峰带宽很重要；
4. **先月付再长期**：先确认自己的手机和网络能稳定在线，再考虑续费。

## 六、常见问题

### Telegram 怎么设置中文？

官方版支持切换中文界面，方法见：[Telegram 怎么设置中文](/blog/telegram-chinese-setting/)。

### 电报和纸飞机是一个东西吗？

是。电报是 Telegram 的直译，纸飞机来自它的 Logo，TG 是缩写。

### Telegram 安全吗？

官方版本本身是正规软件，风险主要来自山寨客户端和群里的诈骗信息。只从官方渠道下载，不要点击陌生人发来的链接，不要向任何人透露登录验证码。
